# Установщик Circuit Editor

Для сборки нужны Windows x64, .NET 8 SDK из [global.json](../global.json), Inno Setup 6.3 или новее в ветке 6 и Windows PowerShell 5.1 или PowerShell 7. Компилятор устанавливается отдельно. При первом запуске нужен доступ к NuGet и к официальным серверам Microsoft.

Из корня репозитория:

```powershell
.\installer\build-installer.ps1
```

При нестандартной установке компилятора передайте `-IsccPath` с путём к `ISCC.exe`. Готовый файл сохраняется в [start/](../start), имя — `setup.exe`. Туда попадает только готовый EXE. Рабочие файлы сборки удаляются из `%TEMP%/CircuitEditor-work/installer/`.

## Как устроена сборка

- `build-installer.ps1` публикует чистую framework-dependent сборку Release win-x64, проверяет комплект поставки и передаёт версию сборки и пути компилятору. Версия приложения задаётся в [Directory.Build.props](../Directory.Build.props).
- `CircuitEditor.iss` задаёт фиксированный AppId, Program Files, русскую и английскую локализации, ярлыки, обработку обновления и удаления. Windows Restart Manager запрашивает обычное закрытие работающего приложения. Сохраните открытый проект, если приложение об этом спросит.
- Runtime хранится в игнорируемом `.cache/`. При каждой сборке скрипт читает официальные метаданные канала .NET 8, выбирает текущий Desktop Runtime **win-x64** и сверяет SHA-512 и подпись Microsoft, даже когда EXE есть в кэше. Для обновления не меняйте версию в `.iss`. Повторите сборку. Если конкретный файл кэша повреждён, удалите его и повторите проверку.
- Setup работает офлайн. При отсутствии .NET Desktop Runtime 8 x64 обычный мастер предлагает установить встроенный пакет. Тихая установка устанавливает его автоматически. В случае отказа или ошибки приложение остаётся установленным, запуск из мастера скрывается. Код `3010` означает, что перед запуском нужна перезагрузка.
- Тихое удаление сохраняет данные. При обычном удалении мастер предлагает удалить `%LocalAppData%/CircuitEditor/` текущего пользователя, только если учётная запись удаления совпадает с учётной записью рабочего стола и путь безопасен. Другие профили и .NET Runtime не удаляются. Автосохранение приложения использует системную временную папку.

## Проверка

На Windows x64 откройте установщик, пройдите русские или английские страницы, выберите обычную папку или путь с пробелами, затем запустите программу. Откройте **Файл → Примеры → Uno · мигающий светодиод**, нажмите **Старт схемы**. Выполните установку ещё раз поверх той же версии и проверьте запись в «Установленных приложениях».

```powershell
.\start\setup.exe /VERYSILENT /NORESTART /DIR="D:\Circuit Editor"
# Из выбранной папки, после остановки сеанса и закрытия программы:
.\unins000.exe /VERYSILENT /NORESTART
```

Проверьте удаление с сохранением данных и с подтверждённой очисткой в отдельном тестовом профиле. Для проверки установки .NET без сети используйте чистую Windows Sandbox или виртуальную машину без Desktop Runtime 8 x64. Установщик приложения не подписан сертификатом. SmartScreen может показывать предупреждение о неизвестном издателе. [Официальная загрузка .NET Desktop Runtime 8](https://dotnet.microsoft.com/download/dotnet/8.0)

### Проверено на Windows 11 x64

- Inno Setup 6.7.3 собрал релизный `setup.exe` с подписанным Desktop Runtime 8.0.34. Сборка приложения без предупреждений, 533 теста прошли.
- Отдельная сборка мастера для текущего пользователя проверила обычный путь и путь с пробелами и кириллицей, регистрацию приложения, ярлыки, обновление с закрытием работающего экземпляра и тихое удаление.
- Из тестовой установки открыт Uno Blink и запущена симуляция. Репозиторий журнала записал диагностику в `%LocalAppData%`, дополнительных файлов в каталоге установки не обнаружено.
- Отсутствующий runtime и ответы `0`, `3010`, `1638`, `1603` имитировались заглушкой в отдельной тестовой сборке. Отдельно проверено сохранение и удаление синтетических данных; при удалении подтверждение подано тестом. Windows Sandbox отключена. Установка в Program Files с повышением прав, действия на чистой ОС без .NET 8 и SmartScreen не проверялись.
- Inno Setup предупреждает, что имя `setup.exe` включает режим совместимости Windows. Это имя сохранено по требованиям к релизу.
