# Circuit Editor для начинающих

## 1. Запустите свой первый скетч

1. В меню **Справка → Учебные примеры** выберите **Uno · мигающий светодиод**. Пример открывается как копия. Свою версию можно сохранить под новым именем.
2. В **Макете** найдите плату Arduino Uno, резистор и светодиод. Провод идёт от контакта **D13** через резистор к светодиоду и возвращается к **GND**, общему контакту цепи. Резистор ограничивает ток.
3. Откройте вкладку **Код**. Arduino называет такую программу *скетчем*. Внутри фигурных скобок `setup()` записывают настройку, которая выполняется один раз. Внутри `loop()` записывают действия, которые Arduino повторяет.
4. Нажмите **Запустить** вверху. Редактор переключится на макет. Внешний светодиод и маленький индикатор **L** на Uno будут мигать.
5. Нажмите **Стоп**, вернитесь в **Код** и замените оба числа в `delay(250)` на `500`. Число задаёт паузу в миллисекундах. Запустите снова и сравните скорость мигания.
6. Выберите **Файл → Сохранить как…**. Файл `.circ` содержит детали, провода, расположение на холсте и код.

## 2. Разберитесь с рабочим окном

| Где | Что там делать |
|---|---|
| **Макет** | Ставить детали, подключать провода и наблюдать работу цепи |
| **Схема** | Читать ту же цепь по условным обозначениям и переставлять их для ясности |
| **Код** | Писать, исправлять и запускать скетч |
| **Микросхема** | Собирать цифровые микросхемы и проверять их на отдельном стенде |
| **Компоненты** | Находить детали по названию и добавлять их по миниатюрам |
| **ERC** в строке состояния | Открывать список проблем и расчёты |

Свойства появляются после выбора детали или провода. У резистора можно поменять сопротивление. У провода можно переключить тип изгиба.

## 3. Подключите деталь и проверьте цепь

1. Найдите деталь в палитре **Компоненты** и перетащите на макет. Можно дважды щёлкнуть по миниатюре, затем указать место установки. Для поворота выделите деталь и нажмите **Повернуть**.
2. Если используете макетную плату, помните, что в одном ряду отверстия **A–E** соединены. **F–J** образуют отдельную группу. Например, A8 и E8 имеют общий контакт, а A8 и A9 — разные. Центральная щель разделяет две стороны. Две ноги светодиода должны попасть в разные группы.
3. Включите **Провод** над холстом, щёлкните по первому контакту и затем по второму. Для ломаной включите **Прямые сегменты**. Чтобы поменять трассу готового провода, выберите его и потяните за линию. Чтобы переподключить, потяните за конец. Esc отменяет незавершённый провод.
4. Наведите курсор на провод, чтобы увидеть оба контакта в строке под макетом. Инструмент **Подсветить электрический узел** слева показывает всё, что электрически связано с выбранным контактом. Пересечение двух линий на экране само по себе связи не создаёт.
5. Откройте **Схема → Проверить соединения**. Щёлкните по найденной проблеме, чтобы перейти к связанному элементу. В том же меню **Рассчитать цепь** показывает поддерживаемые напряжения и токи.
6. Если нужно подписать часть макета, выберите инструмент **Текст** и щёлкните по свободному месту. Щёлкните по готовой подписи, чтобы изменить или удалить её. Колесо меняет масштаб, удержание средней кнопки с движением мыши сдвигает вид.

## 4. Пишите и редактируйте код

В новом проекте уже есть пустые `void setup()` и `void loop()`. Пишите команды между фигурными скобками. Например, `pinMode(13, OUTPUT)` настраивает контакт 13 для подачи сигнала, а `digitalWrite(13, HIGH)` включает высокий уровень.

В верхней части редактора выберите семейство платы. Если на макете одна плата того же семейства, оставьте **Авто**. Если плат несколько, укажите обозначение нужной, например U1. Для старого проекта редактор дополняет скетч недостающими функциями, когда это можно сделать без вмешательства в существующие команды.

### Сочетания редактора по умолчанию

| Клавиши | Действие |
|---|---|
| `Ctrl+D` | Скопировать текущую строку ниже. Если выделено несколько строк, скопировать блок |
| `Alt+↑` / `Alt+↓` | Переместить целую строку или выделенные строки |
| `Ctrl+Shift+K` | Удалить строку или выделенные строки |
| `Ctrl+/` | Добавить или снять комментарий `//` |
| `Ctrl+F` / `Ctrl+H` | Найти текст или заменить его |
| `F3` / `Shift+F3` | Перейти к следующему или предыдущему совпадению |
| `Ctrl+G` | Перейти к строке по номеру |
| `Ctrl+Space` | Посмотреть подсказки по командам и именам |
| `Ctrl+Z` / `Ctrl+Y` | Отменить или повторить правку кода |

Щёлкните в тексте, прежде чем дублировать, перемещать или удалять строки. **Файл → Сохранить** сохраняет весь проект. **Код → Экспорт .ino** создаёт скетч для Arduino IDE, если хотите загрузить программу на физическую плату.

### Как изменить сочетание

1. Откройте **Справка → Горячие клавиши** и найдите действие по названию или текущим клавишам.
2. Выберите строку и щёлкните поле **Введите новое сочетание**. Нажмите нужные клавиши. После успешного назначения изменение действует сразу и сохраняется при перезапуске.
3. Если сочетание занято в том же режиме, окно укажет конфликт. **Сбросить выбранное** возвращает заводской вариант для одной строки. **Сбросить все** восстанавливает весь набор. Esc и стандартные сочетания поля ввода остаются фиксированными.

## 5. Выберите способ запуска

- **Запустить** вверху выполняет скетч в виртуальном Arduino. Если вы поменяли команды, нажмите **Стоп**, затем запустите снова. Пауза позволяет продолжить с того же места.
- **Макет → Параметры симуляции → Старт схемы** запускает схему с выбранным встроенным сценарием или ручными сигналами. Например, сценарий мигания отправляет сигналы на D13 сам, без чтения скетча.

Учебный запуск выполняет распространённые GPIO-команды, условия и таймер, а также команды из примеров LCD I²C и DHT. Для остальных библиотек и загрузки на реальную плату используйте Arduino IDE. Если кнопка запуска сообщает об ошибке, проверьте, что на макете есть плата нужного семейства, а затем откройте сообщение с номером строки.

## 6. Продолжите с готовыми примерами

В **Справка → Учебные примеры** есть девять проектов. Для каждого можно запустить сохранённый скетч через **Запустить**.

| Проект | Что проверить |
|---|---|
| Мигающий светодиод | Измените обе задержки в `delay()` и сравните частоту мигания |
| Кнопка управляет светодиодом | Нажмите SW1 на макете. Светодиод реагирует на положение кнопки |
| Два уровня яркости | Светодиод на D9 чередует яркое и слабое свечение |
| Мигание без delay() | Поменяйте интервал в условии `millis() - previous >= 250` |
| Два светодиода по очереди | Увеличьте первую паузу, чтобы один цвет горел дольше |
| Uno · текст на LCD I2C | Замените текст в `lcd.print()` и перезапустите |
| ESP32 · DHT22 и Serial | Откройте **Вывод** в нижней панели. Сравните напечатанные значения с настройками датчика |
| Дешифратор 2→4 | Меняйте состояния A0 и A1. Из четырёх светодиодов горит один. Пустые функции допустимы, потому что выходом управляет сама микросхема |
| 74HC595 · бегущие огни | После запуска кратко нажмите RESET. Импульсы D13 по очереди заполняют и очищают цепочку светодиодов |

## 7. Найдите нужный раздел справки

Откройте **Справка → Документация**. Вверху всегда видна навигация. **Первые шаги** объясняют интерфейс, **Уроки с кодом** дают упражнения со скетчами, **Uno**, **Nano** и **ESP32** ведут к инструкциям по подключению деталей. В разделе **Ошибки** найдите код или несколько слов сообщения.

Внутри раздела можно искать по названию, контактам и коду. Выберите главу слева или переходите внизу кнопками **Предыдущая** и **Следующая**. Чтобы вернуться к общему списку разделов, нажмите **Оглавление**.
