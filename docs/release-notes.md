# Circuit Editor v1.0

Редактор электрических схем для Arduino Uno, Nano и ESP32. В одной программе можно собрать макет с breadboard и перемычками, посмотреть условную схему и 3D, выполнить ERC и учебный DC-расчёт, написать скетч, запустить симуляцию с приборами и создать цифровую DIP-микросхему. В комплекте пять учебных проектов.

## Запуск

1. Скачайте `CircuitEditor-win-x64.zip` и распакуйте архив целиком.
2. Откройте `CircuitEditor.App.exe`.
3. Выберите **Файл → Примеры → Uno · мигающий светодиод** и нажмите **Старт схемы**.

Требуется Windows x64. Поставка автономная, отдельная установка .NET не нужна. Для удобной работы с боковыми панелями и 3D рекомендован экран 1920×1080.

## Ограничения

- Симуляция учебная. Скетчи выполняются в пределах поддерживаемого подмножества Arduino, без компиляции произвольного C++ и внешних библиотек.
- DC-решатель не моделирует переходные процессы конденсаторов и катушек.
- Проект использует одну breadboard. 3D предназначен для просмотра, выбора деталей и экспорта.
- Конструктор поддерживает цифровые DIP, таблицы истинности и логические графы. Аналоговые микросхемы, SOIC/QFP и C#-скрипты в поставку не входят.
