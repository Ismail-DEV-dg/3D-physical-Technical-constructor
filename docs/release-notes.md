# Circuit Editor 1.0.0

Редактор электрических схем и учебных скетчей для Arduino Uno, Nano и ESP32. В комплекте девять учебных проектов.

## Что нового

- Пять рабочих вкладок, две темы, фотопалитра с поиском и заставка с северным сиянием. Во встроенной справке появились главы для новичков, уроки и обзор приложения. Горячие клавиши переназначаются двойным щелчком по сочетанию.
- Детали можно перетаскивать из библиотеки сразу на макетную плату. Предварительная подсветка показывает будущие отверстия, клавиша R поворачивает деталь до установки. Есть прямые и плавные перемычки, заметки, линейка и просмотр электрического узла.
- Пассивный разветвитель соединяет 2–8 выходов общей шиной. Напряжение доступно в подсказке контакта.
- В редакторе доступны каркас `setup()` и `loop()`, дублирование и перемещение строк. Кнопка «Запустить» выполняет скетч, а «Старт схемы» в параметрах запускает сценарий или ручной GPIO.
- Поддерживаемые команды скетча управляют отдельными экземплярами LCD, OLED и сервоприводов. Можно опрашивать несколько аналоговых, DHT и ультразвуковых датчиков по отдельным контактам или адресам.
- В 3D уточнены корпуса, углубления и выводы. Можно выбрать компонент в сцене и экспортировать PNG или OBJ. Кэширование уменьшает число операций при отрисовке дисплеев и 3D-текстур.
- Прежние файлы `.circ` v4 и `.chip` v1 открываются в этой версии.

## Установка и запуск

- **setup.exe** — основной установщик. Скачайте его из Releases и пройдите мастер. При отсутствии .NET Desktop Runtime 8 x64 мастер предложит установить встроенную среду. Для самой установки доступ к сети не нужен. Установщик не подписан, поэтому Windows SmartScreen может показать предупреждение.
- **CircuitEditor-win-x64.zip** — автономный переносимый вариант. Распакуйте архив целиком, запустите `CircuitEditor.App.exe`.

В приложении выберите **Справка → Учебные примеры → Uno · мигающий светодиод** и нажмите **Запустить**. Требуется Windows 10 (1607 или новее) либо Windows 11 на x64. Для боковых панелей и 3D рекомендован экран 1920×1080. [Официальные сведения о .NET 8](https://dotnet.microsoft.com/download/dotnet/8.0)

Сборка установщика из исходников — `.\installer\build-installer.ps1`. Порядок загрузки файлов в GitHub Releases описан в [RELEASE.md](../RELEASE.md).

## Ограничения

- Симуляция учебная. Скетчи выполняются в пределах поддерживаемого подмножества Arduino, без компиляции произвольного C++ и внешних библиотек.
- DC-решатель не моделирует переходные процессы конденсаторов и катушек.
- Проект использует одну breadboard. 3D предназначен для просмотра, выбора деталей и экспорта.
- Конструктор поддерживает цифровые DIP, таблицы истинности и логические графы. Аналоговые микросхемы, SOIC/QFP и C#-скрипты в поставку не входят.
