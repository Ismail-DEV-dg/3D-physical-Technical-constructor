# Этап 4 — перемычки, история, файлы и экспорт

Реализован согласованный объём этапа 4. Электрические узлы, провода в «Схеме», ERC, симуляция и редактор кода остаются для следующих этапов.

## Поведение

- Инструмент «Перемычка»: два клика по физическим контактам/отверстиям, предпросмотр, Esc. Плавная кривая через редактируемые узлы; выделение, hover, семь цветов, перенос обоих концов, Del. Для добавления изгиба потянуть выбранную линию; существующие узлы потянуть за кружки.
- Связность задана только парой устойчивых ссылок. Конец компонента следует за его контактом, включая предпросмотр перемещения и вставку в другое отверстие. Нулевая длина, обратный дубликат и неизвестные концы отклоняются в строке состояния.
- CommandHistory: 200 действий, отдельные сохранённые состояния, Undo/Redo через меню, кнопки, Ctrl+Z/Y/Shift+Z. Добавление, движения/повороты обоих видов, удаление, вставка/занятость, шаг ножек, все редакторы свойств и перемычки включены в историю. Полный жест записывается один раз; Esc восстанавливает исходные данные без записи.
- Команда ProjectEditCommand хранит независимые снимки изменяемых экземпляров, раскладок, привязок, перемычек и счётчиков. Библиотечные определения разделяются как неизменяемые объекты; JSON на кадрах жеста не используется.
- Ctrl+C/V: внутренний буфер проекта, новые ID/обозначения, параметры сохраняются, вставка слева от breadboard без занятых отверстий. Копируются только перемычки с обоими концами на копируемых компонентах. Вставка — одно действие.
- Создать, открыть, сохранить, сохранить как; заголовок со звёздочкой, save/discard/cancel, включая системное закрытие окна. История очищается после открытия/создания. Недопустимый файл проверяется в отдельной модели до замены текущего проекта.
- Автосохранение каждые 60 секунд в `%TEMP%/CircuitEditor/recovery.circ`, пропуск незавершённого жеста. После незавершённого сеанса предлагается восстановление; восстановленный документ требует сохранения. Нормальное завершение очищает recovery. Последние десять файлов доступны через меню.
- PNG обоих представлений: весь документ без панелей/выделения и текущей камеры, масштабы 1×/2×/4×. Ограничения размера: 16384 px на сторону и 64 млн пикселей, с предложением уменьшить масштаб. Динамическая ручка потенциометра включена.
- SVG только «Схемы»: геометрия и контуры глифов, без растра и зависимости от установленных шрифтов. SVG макета не реализован согласно согласованным границам.
- BOM CSV: UTF-8 с BOM, `;`, экранирование кавычек/переводов строк; группировка по типу, номиналу и применимым параметрам, список обозначений и количество.

## Формат .circ

`schemaVersion: 1`, `libraryVersion: "1"`. Производственных миграций пока нет. IProjectMigration и цепочка преобразований готовы; тестовая миграция искусственной версии 0→1 находится только в Tests. Будущие версии отклоняются.

Документ содержит `components`, `counters`, `mockup`, `schematic`, `breadboards`, `bindings`, `wires`, `view`. Компонент хранит `definitionId`, `footprintId`, собственные `id/reference/value` и применимые параметры. Breadboard хранит `definitionId/id/x/y`. Определения компонентов, контактов корпусов и топология отверстий в файл не встраиваются. Неизвестные ID и несовместимая libraryVersion сообщаются пользователю; текущий проект сохраняется.

Цвет экземпляра есть только у LED. Цвет резистора определяется полосами; прочие компоненты используют оформление библиотечного рисовальщика. В .circ отсутствуют неприменимые color, capacitorKind, potentiometerAngle и входные условия. I2C сохраняется только у поддерживающих его компонентов. В инспекторе отсутствуют произвольные номиналы у плат, дисплеев и датчиков; напряжение показано как справочное питание у компонентов с Power, у батареи берётся выбранное значение.

## Ручная проверка

1. `dotnet run --project CircuitEditor.App`. Перенести резистор и LED. Проверить отсутствие цвета/питания у резистора, список номиналов и полосы. Вставить детали в свободные отверстия.
2. Включить «Перемычка», нажать контакт, затем отверстие. Между кликами подвигать мышь; Esc отменяет предпросмотр. Проверить нулевую длину и дубликат: ошибка в строке состояния.
3. Выбрать провод; потянуть его линию для изгиба, затем кружок узла и конца. Выбрать цвет. Переместить вставленный компонент: провод следует за контактом. Del удаляет провод; в «Схеме» его нет.
4. Проверить Ctrl+Z/Y/Shift+Z, включая номиналы, слайдеры датчиков, вращение ручки, вставку и перенос компонентов. Полный жест отменяется одним шагом; Esc во время жеста ничего не добавляет.
5. Ctrl+выбор нескольких деталей, Ctrl+C/V: новые обозначения, свободное размещение, только внутренние перемычки. Один Undo убирает вставку.
6. Ctrl+S, Save As, New, Open; проверить оба размещения и камеры, очищенную историю и звёздочку. Отказаться от закрытия/нового проекта с несохранёнными правками. Открыть испорченный файл, изменить ID/версию в копии JSON: прежний проект остаётся.
7. Для recovery изменить проект, подождать более минуты, аварийно завершить только проверочный экземпляр приложения и перезапустить. Согласиться восстановить; затем сохранить проект. Нормальное закрытие не предлагает recovery.
8. Файл → PNG в обоих видах и с разным масштабом; SVG на вкладке «Схема»; CSV BOM открыть в Excel и проверить кириллицу, `;` и группировку.
